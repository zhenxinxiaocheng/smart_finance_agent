# 总资产统计与现金基准设计

## 目标

将总资产从股票、基金详情页移到统计页面，并统一现金、日常收支和投资资产的计算口径。用户画像只负责维护现金基准；统计页面负责展示总资产及构成；投资详情仅在后台使用财富数据生成数量参考和财务警告。

## 统一口径

用户画像中的“当前现金余额”指非投资账户的日常现金，不包含证券或基金投资账户中的可用余额。每次保存现金余额时同时记录基准时间，基准时间之前的收入和支出视为已经包含在该余额中。

```text
日常现金
= 现金基准
+ 基准时间后的日常收入
- 基准时间后的日常支出
- 基准时间后的投资净转入

投资资产
= 投资账户现金
+ 股票、基金持仓当前市值

总资产
= 日常现金
+ 投资资产
```

投资净转入为正时，日常现金减少、投资账户现金增加；投资转出时方向相反。因此投资入金、出金以及股票基金买卖只改变资产构成，不应被重复计算为收入或支出。股票和基金使用当前市值计算投资资产，行情变化会直接影响总资产。

## 后端设计

继续使用现有 `/api/wealth` 模块作为唯一财富数据源，不在统计页面分别拼接多个接口。

### 现金基准

将现有以“总资产”为输入的基准语义调整为“当前日常现金余额”：

- 基准记录保存用户、现金基准金额和基准时间。
- 更新现金基准时直接保存日常现金，不再扣除当前投资资产。
- 基准更新后，只累计新基准时间之后的收入、支出和投资划转。
- 为兼容已有数据库结构，可优先复用现有字段并迁移语义；接口和 DTO 使用明确的 `cashBaseline`、`cashBaselineAt` 命名，避免继续暴露“录入总资产”的概念。

### 财富汇总

`GET /api/wealth/overview` 返回：

- `totalAssets`：初始化后返回当前总资产；未初始化时为空，避免把投资资产误认为完整总资产。
- `dailyCash`：按现金基准和后续流水推导的日常现金。
- `investmentTotal`：投资账户现金和持仓当前市值之和。
- `investmentCash`：投资账户可用现金。
- `holdingMarketValue`：股票基金持仓当前市值。
- `incomeAfterBaseline`、`expenseAfterBaseline`：基准后的日常收支。
- `netInvestmentTransfer`：基准后的投资净转入。
- `cashBaseline`、`cashBaselineAt`、`initialized` 和独立警告。

`PUT /api/wealth/baseline` 接收当前日常现金余额。金额必须大于或等于零；更新成功后立即返回重新计算的财富汇总。

### 分析边界

投资分析服务可以继续读取财富汇总，用于参考数量和资金警告，但总资产、现金、风险偏好不能改变技术评分、技术信号、支撑位或压力位。

## 前端设计

### 用户画像

在财务画像的基础信息区域增加“当前现金余额”输入及现金基准时间说明。字段文案明确提示“不包含投资账户余额”。首次填写或金额发生变化时才保存现金基准，并以保存时刻重新建立基准；仅修改画像的其他字段不能重置基准时间。

用户画像不展示完整总资产，也不承担投资构成分析。

### 统计页面

统计页面成为总资产的唯一主入口：

- 资产汇总首卡显示当前总资产。
- 其余卡片显示日常现金、投资资产和当前统计周期的收支结余。
- 在汇总卡下展示资产构成：日常现金、投资账户现金、股票基金当前市值。
- 保留现有近七日收入、支出和结余图表。
- 期间收入、期间支出和交易笔数继续按统计区间计算，不再用“收入减支出”代替总资产。
- 暂不提供历史总资产曲线；没有每日持仓市值快照时，任何历史曲线只能标记为“收支走势”或“累计收支结余”。

### 投资详情

移除股票基金详情页顶部的“总资产”按钮、编辑弹窗、相关页面状态和保存逻辑。财富数据仅通过投资分析响应中的数量参考与财务警告间接体现。

## 数据流

1. 用户在财务画像填写当前日常现金，系统保存金额和基准时间。
2. 新增日常收入或支出后，财富汇总按基准时间自动累计。
3. 投资入金从日常现金转为投资账户现金；投资出金反向处理。
4. 股票基金买卖在投资账户现金与持仓之间转换，不额外改变总资产。
5. 最新行情更新持仓当前市值，统计页下次刷新时显示新的投资资产与总资产。

## 异常与空状态

- 未设置现金基准时，`totalAssets` 返回空值，统计页将总资产显示为“待初始化”；投资资产仍单独展示，并提示前往用户画像填写当前现金。
- 行情不可用时沿用投资模块的缓存市值并显示数据时间和缓存状态。
- 收支或投资子模块请求失败时，不使用零值覆盖上一次成功数据；统计页面分别展示对应错误提示。
- 现金基准不能为负数，前后端都校验。

## 测试与验收

- 验证现金基准加收入、减支出的计算。
- 验证投资入金和出金只改变资产构成，总资产不重复增减。
- 验证股票基金买卖只在投资现金和持仓市值间转换。
- 验证行情涨跌通过持仓当前市值影响总资产。
- 验证重新设置现金基准后，旧收支不被重复累计。
- 验证统计页总资产来自财富接口，不再等于统计周期收入减支出。
- 验证投资详情页不再出现总资产入口。
- 验证未初始化、缓存行情和部分接口失败状态。
- 最终运行相关 Java、前端测试与前端构建。

## 暂不实施

- 每日总资产快照和历史净值曲线。
- 银行账户自动同步。
- 多币种现金折算。
- 将财务警告参与技术评分。
