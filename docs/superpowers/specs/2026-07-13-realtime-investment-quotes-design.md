# 投资行情准实时更新设计

## 目标

- A 股持仓在交易时段以 3 秒周期更新最新价。
- 同步由后端执行，不依赖浏览器标签页是否处于前台。
- 前端显示精确到秒的行情更新时间，并在重新进入页面时立即拉取最新缓存。
- 场外基金继续使用每日公布的单位净值，不伪装成实时价格。

## 数据流

1. Python 行情服务使用当前网络实测可用的腾讯 HTTP 行情接口按股票代码获取单股最新报价；新浪行情作为备用源，AKShare 日线作为最终降级。
2. Java 定时任务查询当前用户资产中的股票产品，在 A 股交易时段每 3 秒批量触发报价更新。
3. Java 是唯一数据库写入者，将最新价、行情时间、来源及同步状态保存到行情表和资产状态。
4. 前端 `/stocks` 每 3 秒读取资产列表，不直接请求第三方行情源；窗口重新获得焦点时立即刷新。

## 时间与状态

- 股票行情新增精确到秒的 `fetchedAt`，页面展示 `HH:mm:ss`，原 `dataDate` 继续表示交易日期。
- 交易时间按工作日 `09:15-11:30`、`13:00-15:00` 执行；交易日历后续可替换简单工作日判断。
- 非交易时段停止高频请求，保留最后一笔有效行情。
- 行情请求失败时不清空旧价格，状态改为“数据延迟”，保存错误摘要和最后成功时间。

## 接口与兼容性

- Python 新增独立实时行情接口并返回 `fetchedAt`，避免每 3 秒重复下载产品名称列表；失败时降级到已有日线行情并返回 warning。
- Java 资产视图增加 `fetchedAt`，原有字段保持兼容。
- 单项刷新按钮继续可用，并立即请求该股票的实时行情。
- 基金解析和净值同步保持现状。

## 测试

- Python 固定样本验证实时价格字段、报价时间和日线降级。
- Java 验证定时任务仅同步股票、失败保留旧价、更新时间正确。
- 前端验证 3 秒轮询、卸载清理定时器、窗口重新聚焦立即刷新和更新时间展示。
- 最终运行 Python 用例、后端全量测试、前端构建及三进程健康检查。
