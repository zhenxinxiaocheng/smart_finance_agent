# 简化投资列表设计

## 目标

把 `/stocks` 从专业账本录入页改成普通用户可理解的“自选列表 + 持仓管理”。用户首次只需选择股票或基金并输入代码，系统完成标的识别；添加后再维护数量、成本和备注。

## 主页面

- 顶部仅保留类型切换、代码输入框和“添加”按钮。
- 主体为资产列表，展示代码、名称、市场、最新价、数据日期、数量、成本、市值、盈亏和数据状态。
- 每行提供查看、编辑、刷新和删除操作。
- 点击行打开右侧详情抽屉，展示持仓详情、行情状态和内部流水记录。
- 账户、CSV 导入、原始流水和同步批次收进“高级功能”，不占据主操作区。

## 数据与交互

- A 股代码根据首位数字推断交易所；境内基金由用户先选择“基金”，避免与股票同代码冲突。
- 添加前调用产品识别接口，成功后返回标准化代码、名称、市场、币种和数据来源。
- 数量和成本允许为空；只有用户填写后才形成持仓投影。
- 编辑数量或成本时，由 Java 服务生成更正流水并重建持仓，不直接覆盖历史账本。
- 删除表示移出用户资产列表；已有历史流水保留，避免破坏审计记录。
- 港股、美股在数据源不可用时明确显示不可用原因，不伪造行情。

## 接口

- `POST /api/investment/assets/resolve`：按类型和代码识别产品。
- `POST /api/investment/assets`：添加用户资产，可不带数量和成本。
- `GET /api/investment/assets`：查询用户资产列表。
- `PUT /api/investment/assets/{id}`：修改数量、成本和备注，通过更正流水实现。
- `DELETE /api/investment/assets/{id}`：移出列表并保留历史。
- `POST /api/investment/assets/{id}/sync`：刷新单个标的数据。

## 验收

- 新用户无需先创建账户或理解流水类型即可添加股票或基金。
- 输入 `600519` 能识别并添加 A 股；输入 `000001` 且选择基金时能识别基金。
- 添加后可以查询、编辑和删除。
- 数据获取失败时展示来源和错误，不显示虚假的最新价格。
- 原有不可变流水、CSV 和 Agent 分析能力继续可用。
